# Telekinesis
Telekinesis uses an object or opens a container from a distance, as if the caster had double-clicked it. It doesn't work on trapped containers. Aiming it at one shows *The trap resists your magic.*, and the spell isn't cast, so it uses no mana or reagents. Traps are disarmed with [Remove Trap](/remove_trap), or with [Magic Untrap](/magic_untrap) on the weakest chests.

| Property | Value |
|:-|:-:|
| Circle | 3 |
| Mana | 9 |
| Words | Ort Por Ylem |
| Reagents | Bloodmoss and mandrake root |
| Range (tiles) | 12 |
