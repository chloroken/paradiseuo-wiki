# Quickstart Guide
In this guide, you will learn how to join the *Paradise* private UO shard.

- **REMINDER**: This server is in alpha. Play at your own risk.

## Step 1 - Install Ultima Online
  - We will only install the *game files* with this launcher
1. Install Ultima Online's [Classic Client](https://downloads.eamythic.com/uo/installers/UOClassicSetup_7_0_24_0.exe) (18MB)
1. Run this `Classic Client` and let it patch (2.6GB)
1. Close the `Classic Client`
## Step 2 - Set up TazUO
  - This is the launcher we will use to play the game
1. Download the [TazUO Launcher](https://github.com/PlayTazUO/TUO-Launcher/releases/tag/TazUO-Launcher) (~75MB)
1. Unzip the files, rename the folder to `TazUO`, and move it where you want it
1. Double click `TazUOLauncher.exe` (Linux uses `TazUOLauncher`)
1. In the top-left menu, select `Tools` -> `Install latest main build`
1. In the launcher, click `Select a profile` then `[ Edit Profiles ]`
1. Fill out your profile (anything not listed here can be ignored):
    - Set `Profile Name` to something like `"Main"`
    - Set `Connection` to `165.245.194.178` and `2593`
    - Set `UO Directory` to the `Classic Client` directory (step 1)
    - Click `Save` and close the `Profile Editor` window
    - Select your new profile and click `Play`
1. Your account is created on your first login
1. Install [map markers](https://github.com/chloroken/paradisemapmarkers) if desired
