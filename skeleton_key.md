# Skeleton Key
A skeleton key lowers a locked container's [Lockpicking](/lockpicking) requirements by `10` when used instead of a [lockpick](/lockpick).

A skeleton key has `10` charges. Each lock it successfully picks uses one charge, and the key is destroyed when the last charge is used. A failed attempt never uses a charge.

## Drop Sources
- Treasure chests have a `Map Level * 1%` chance to hold a skeleton key.
- [Messages in a bottle](/message_in_a_bottle) have a `Message Level * 0.5%` chance to drop a skeleton key.
