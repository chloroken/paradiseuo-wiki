# Quickstart Guide
This guide explains how to join the *Paradise* private Ultima Online shard.

**This server is in alpha. Players join at their own risk.**

## Step 1: Install Ultima Online
The Ultima Online launcher is only used to install the game files.

1. Install Ultima Online's [Classic Client](https://downloads.eamythic.com/uo/installers/UOClassicSetup_7_0_24_0.exe) (18 MB).
1. Run the Classic Client and let it patch (2.6 GB).
1. Close the Classic Client.

## Step 2: Set Up TazUO
TazUO is the launcher used to play the game.

1. Download the [TazUO Launcher](https://github.com/PlayTazUO/TUO-Launcher/releases/tag/TazUO-Launcher) (about 75 MB).
1. Unzip the files, rename the folder to `TazUO`, and move it anywhere.
1. Double-click `TazUOLauncher.exe` (on Linux, `TazUOLauncher`).
1. In the top-left menu, select `Tools`, then `Install latest main build`.
1. In the launcher, click `Select a profile`, then `[ Edit Profiles ]`.
1. Fill out the profile. Anything not listed here can be ignored:
    - Set `Profile Name` to something like `Main`.
    - Set `Connection` to `165.245.194.178` and `2593`.
    - Set `UO Directory` to the Classic Client's folder from step 1.
    - Click `Save` and close the `Profile Editor` window.
    - Select the new profile and click `Play`.
1. An account is created automatically on first login.
1. Install the [map markers](https://github.com/chloroken/paradisemapmarkers) if desired.
