# Quickstart
This guide explains how to join the *Paradise* private Ultima Online shard.

**This server is in alpha. Players join at their own risk.**

## Step 1: Installing Ultima Online
The Ultima Online launcher is only used to install the game files.

1. The [Classic Client](https://downloads.eamythic.com/uo/installers/UOClassicSetup_7_0_24_0.exe) installer (18 MB) installs Ultima Online.
1. Running the Classic Client patches the game files (2.6 GB).
1. Once patching finishes, the Classic Client can be closed.

## Step 2: Setting Up TazUO
TazUO is the launcher used to play the game.

1. The [TazUO Launcher](https://github.com/PlayTazUO/TUO-Launcher/releases/tag/TazUO-Launcher) downloads as a zip file (about 75 MB).
1. The unzipped folder is renamed to `TazUO` and can go anywhere.
1. `TazUOLauncher.exe` (on Linux, `TazUOLauncher`) opens the launcher.
1. In the top-left menu, `Tools`, then `Install latest main build`, installs the game client.
1. In the launcher, `Select a profile`, then `[ Edit Profiles ]`, opens the profile editor.
1. The profile needs these settings. Anything not listed here can be ignored:
    - `Profile Name`: something like `Main`
    - `Connection`: `[request access]` and `2593`
    - `UO Directory`: the Classic Client's folder from step 1
1. `Save` stores the profile, and the `Profile Editor` window can then be closed.
1. Selecting the new profile and clicking `Play` starts the game. An account is created automatically on first login.
1. The [map markers](https://github.com/chloroken/paradisemapmarkers) are an optional extra.
