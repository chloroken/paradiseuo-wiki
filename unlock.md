# Unlock
Unlock opens a locked container without [Lockpicking](/lockpicking). The lock opens if the spell's strength reaches the lock's difficulty. Otherwise the caster sees *My spell does not seem to have an effect on that lock.* Unlock only works on containers, not doors, and never on secure containers in a house. It doesn't disarm traps or train Lockpicking.

| Property | Value |
|:-|:-:|
| Circle | 3 |
| Mana | 9 |
| Range (tiles) | 12 |
| Strength | 0.8 * Magery - 4 |
